# D-FlipFlop-Based-PUF

This project implements a Physical Unclonable Function (PUF) using an array of D Flip-Flops (DFFs). The PUF exploits inherent manufacturing variations in semiconductor devices to generate unique and unpredictable digital responses.

Even when identical circuits are designed using the same layout and fabricated using the same process, small variations in transistor characteristics cause each instance to exhibit unique electrical behavior. These variations are used as the source of randomness for generating a device-specific fingerprint.
